## 1. Redis가 뭔가요? 우리가 만들 것은?

**Redis**는 데이터를 **메모리(RAM)** 에 저장하는 아주 빠른 창고입니다.
"이름표(key)"에 "물건(value)"을 붙여 보관하는 방식이라 **Key-Value 저장소**라고 부릅니다.

예: `user:1` 이라는 이름표에 `"Alice"` 라는 값을 저장.

우리가 만들 **Mini Redis**는 다음 명령을 지원합니다.

| 명령 | 하는 일 | 예시 |
| --- | --- | --- |
| `SET 키 값` | 저장 | `SET user:1 "Alice"` |
| `GET 키` | 꺼내기 | `GET user:1` → `"Alice"` |
| `DEL 키` | 삭제 | `DEL user:1` |
| `EXISTS 키` | 있는지 확인 | `EXISTS user:1` |
| `DBSIZE` | 전체 개수 | `DBSIZE` |
| `KEYS` | 전체 이름표 목록 | `KEYS` |
| `EXPIRE 키 초` | 유효기간 설정 | `EXPIRE user:1 10` |
| `TTL 키` | 남은 시간 확인 | `TTL user:1` |
| `CONFIG SET maxmemory 바이트` | 메모리 한계 설정 | `CONFIG SET maxmemory 30` |
| `INFO memory` | 메모리 상태 확인 | `INFO memory` |

그리고 **두 가지 똑똑한 기능**이 있습니다.

1. **LRU 자동 삭제**: 메모리가 꽉 차면 **가장 오래 안 쓴 데이터**를 자동으로 버립니다.
   (LRU = Least Recently Used = 가장 최근에 안 쓰인 것)
2. **TTL(유효기간)**: 정해둔 시간이 지나면 데이터가 자동으로 사라집니다.

## 2. 미리 알아야 할 파이썬 문법 7가지

이 프로젝트에 꼭 필요한 문법만 추렸습니다. 이미 안다면 건너뛰세요.

### ① 클래스(class) — 데이터와 기능을 한 묶음으로

클래스는 "설계도"입니다. 설계도로 실제 물건(객체)을 찍어냅니다.

```python
class Dog:                      # Dog 설계도
    def __init__(self, name):   # 물건을 만들 때 자동 실행되는 함수
        self.name = name        # self = 만들어진 그 물건 자신

    def bark(self):             # 이 물건이 할 수 있는 동작(메서드)
        return self.name + " 멍멍!"

d = Dog("바둑이")     # 설계도로 실제 강아지 한 마리 생성
print(d.bark())       # "바둑이 멍멍!"
```

- `__init__` : 객체가 태어날 때 딱 한 번 실행되는 **생성자**.
- `self` : "나 자신"을 가리킴. 메서드 첫 번째 자리에 항상 씁니다.

### ② None — "아무것도 없음"

```python
x = None              # 비어있다는 뜻
if x is None:         # 비었는지 확인할 땐 == 가 아니라 is 사용
    print("비었어요")
```

### ③ 리스트(list) — 순서 있는 값 묶음

```python
arr = [10, 20, 30]
print(arr[0])         # 10 (0번부터 셈)
arr.append(40)        # 맨 뒤에 추가 → [10,20,30,40]
print(len(arr))       # 4 (개수)
```

### ④ 반복문 while / for

```python
# while: 조건이 참인 동안 반복
i = 0
while i < 3:
    print(i)          # 0, 1, 2
    i = i + 1

# for: 묶음을 하나씩 꺼내며 반복
for x in [10, 20, 30]:
    print(x)
```

### ⑤ 딕셔너리는 "금지"입니다 (중요!)

파이썬에는 키-값을 저장하는 `dict`라는 편한 도구가 있지만,
**이 프로젝트에서는 사용 금지**입니다. 그걸 직접 만드는 게 학습 목표거든요.
대신 우리가 만든 `HashMap`을 씁니다.

```python
# ❌ 금지: data = {}  /  data["k"] = "v"
# ✅ 허용: data = HashMap()  /  data.put("k", "v")
```

> 단, "고정 크기 배열" 용도로 `[None] * 8` 같은 리스트는 써도 됩니다.
> (값을 인덱스 번호로만 접근하는 단순 저장 공간이기 때문)

### ⑥ 튜플(tuple) — 못 바꾸는 값 묶음

```python
point = (3, "k")      # 소괄호
print(point[0])       # 3
# 튜플끼리 비교하면 앞에서부터 차례로 비교됨 → 힙에서 활용
(1, "a") < (2, "a")   # True (1 < 2 이니까)
```

### ⑦ 예외 처리 try / except

```python
try:
    n = int("abc")    # 글자를 숫자로? → 에러 발생
except ValueError:
    print("숫자가 아니에요")   # 에러를 잡아서 처리
```

## 3. 미리 알아야 할 자료구조 개념

### 🔹 자료구조란?

데이터를 **어떻게 담아둘지** 정한 방식입니다. 같은 데이터라도 담는 방법에 따라
속도가 천차만별입니다. 우리는 3가지를 만듭니다.

### 🔹 "O(1)", "O(n)"이 뭔가요? (시간복잡도)

작업에 걸리는 시간이 데이터 양에 따라 **얼마나 늘어나는지** 표현하는 기호입니다.

- **O(1)** : 데이터가 100개든 100만 개든 **항상 일정한 시간**. (빠름! 최고)
- **O(n)** : 데이터가 n개면 시간도 n배. (데이터 많아지면 느려짐)

> 📌 예: 책장에서 책 찾기.
> - 책 위치를 정확히 알면 바로 꺼냄 = **O(1)**
> - 처음부터 한 권씩 확인 = **O(n)**

우리 목표는 핵심 동작을 전부 **O(1)** 로 만드는 것입니다.

### 🔹 만들 자료구조 3가지

| 자료구조 | 한 줄 설명 | 어디에 쓰나 |
| --- | --- | --- |
| **이중 연결 리스트** | 각 칸이 앞/뒤 칸을 손으로 잡고 줄 선 구조 | "사용 순서" 기억 (LRU) |
| **해시맵** | 이름표로 물건을 바로 찾는 사물함 | 키→값 저장 |
| **최소 힙** | 가장 작은 값이 항상 맨 위에 오는 더미 | "가장 빨리 만료될 키" 찾기 (TTL) |

## 5. STEP 1 — 이중 연결 리스트 만들기

📁 `mini_redis/structures/doubly_linked_list.py`

### 무엇을, 왜 만드나?

LRU(가장 오래 안 쓴 것 버리기)를 하려면 **사용한 순서**를 기억해야 합니다.
이중 연결 리스트는 "줄 서기"와 같습니다.

```
[앞=최근 사용]  A ⇄ B ⇄ C  [뒤=오래됨]
```

- 새 데이터나 방금 쓴 데이터는 **맨 앞**으로.
- 메모리가 꽉 차면 **맨 뒤(가장 오래된 것)** 를 버림.

각 칸(노드)은 **앞 칸과 뒤 칸을 양손으로 잡고** 있어서, 줄 중간에서도
양옆만 다시 연결하면 **즉시(O(1))** 빠지거나 이동할 수 있습니다.

### 5-1. 노드(칸) 만들기

```python
class Node:
    """리스트의 한 칸. 앞(prev)·뒤(next)·데이터(data)를 가진다."""
    def __init__(self, data=None):
        self.prev = None   # 앞 칸을 가리킴
        self.next = None   # 뒤 칸을 가리킴
        self.data = data   # 실제 담는 값 (우리는 '키' 문자열을 담음)
```

### 5-2. 핵심 아이디어: 더미(가짜) 칸 2개

빈 리스트나 양 끝을 다룰 때 "앞 칸이 없으면?" 같은 예외 상황이 많아 복잡합니다.
그래서 **맨 앞과 맨 뒤에 가짜 칸(센티넬)** 을 미리 둡니다.

```
[head(가짜)] ⇄ ...실제 데이터... ⇄ [tail(가짜)]
```

이러면 실제 데이터는 **항상 양옆에 칸이 존재**하므로 "없으면?" 걱정이 사라집니다.

```python
class DoublyLinkedList:
    def __init__(self):
        self._head = Node()   # 맨 앞 가짜 칸
        self._tail = Node()   # 맨 뒤 가짜 칸
        self._head.next = self._tail   # 처음엔 head ⇄ tail 만 연결
        self._tail.prev = self._head
        self._size = 0        # 실제 칸 개수
```

### 5-3. 만능 도우미 2개: 끼우기 / 빼기

모든 동작은 결국 "두 칸 사이에 끼우기"와 "한 칸 빼기"의 조합입니다.
이 둘만 잘 만들면 나머지는 쉽습니다.

```python
    def _insert_between(self, node, left, right):
        """left와 right 사이에 node를 끼운다."""
        node.prev = left
        node.next = right
        left.next = node
        right.prev = node
        self._size += 1

    def _unlink(self, node):
        """node를 빼내고, 양옆을 직접 잇는다."""
        node.prev.next = node.next   # 앞 칸의 next를 내 뒤 칸으로
        node.next.prev = node.prev   # 뒤 칸의 prev를 내 앞 칸으로
        node.prev = None
        node.next = None
        self._size -= 1
```

> 🎨 **그림으로 이해**: `A ⇄ B ⇄ C` 에서 B를 빼면
> A의 손을 C에게, C의 손을 A에게 → `A ⇄ C`. B는 자연스럽게 떨어져 나감.

### 5-4. 미션이 요구하는 메서드들

```python
    def insert_front(self, data):
        """맨 앞에 추가하고 그 노드를 돌려준다. (최근 사용 표시)"""
        node = Node(data)
        self._insert_between(node, self._head, self._head.next)
        return node

    def insert_back(self, data):
        """맨 뒤에 추가."""
        node = Node(data)
        self._insert_between(node, self._tail.prev, self._tail)
        return node

    def remove_front(self):
        """맨 앞 칸 제거 후 그 데이터 반환. 비었으면 None."""
        if self._size == 0:
            return None
        node = self._head.next
        self._unlink(node)
        return node.data

    def remove_back(self):
        """맨 뒤 칸 제거 후 데이터 반환. (가장 오래된 것 버릴 때 사용)"""
        if self._size == 0:
            return None
        node = self._tail.prev
        self._unlink(node)
        return node.data

    def remove_node(self, node):
        """특정 노드를 직접 제거. (노드를 이미 알고 있으면 O(1)!)"""
        self._unlink(node)
        return node.data

    def move_to_front(self, node):
        """이미 있는 노드를 맨 앞으로 이동. (방금 사용했다고 표시)"""
        self._unlink(node)
        self._insert_between(node, self._head, self._head.next)

    def size(self):
        return self._size

    def is_empty(self):
        return self._size == 0

    def back_node(self):
        """맨 뒤 실제 노드 반환(없으면 None). LRU 키 찾을 때."""
        if self._size == 0:
            return None
        return self._tail.prev
```

> ✅ **여기서 가장 중요한 것**: `move_to_front`와 `remove_node`가 **O(1)** 이라는 점.
> "노드를 직접 손에 쥐고 있으면" 줄 어디에 있든 즉시 처리할 수 있습니다.
> 그 "노드를 손에 쥐는 방법"은 다음에 만들 해시맵이 제공합니다.

## 6. STEP 2 — 해시맵 만들기

📁 `mini_redis/structures/hash_map.py`

### 무엇을, 왜 만드나?

"이름표(key)로 물건(value)을 바로 찾는 사물함"입니다. `dict` 금지라서 직접 만듭니다.

### 6-1. 핵심 아이디어: 해시 함수

**해시 함수**는 글자(문자열)를 **숫자**로 바꾸는 기계입니다.
이 숫자를 사물함 칸 번호로 쓰면, 이름표만 보고 어느 칸인지 바로 계산됩니다.

```
"user:1"  →  [해시 함수]  →  숫자 38291  →  38291 % 칸수 = 3번 칸
```

우리가 쓸 공식(djb2라고 불리는 유명한 방식):

```python
    def _hash(self, key):
        """문자열 key를 숫자로 바꾼다."""
        h = 5381                       # 시작 숫자(경험적으로 잘 퍼짐)
        for ch in key:                 # 글자 하나씩
            h = h * 33 + ord(ch)       # ord(ch) = 글자의 숫자 코드
            h = h & 0xFFFFFFFF         # 너무 커지지 않게 32비트로 자름
        return h
```

> 💡 `ord("A")`는 65 처럼, 글자마다 정해진 번호를 돌려줍니다.
> `&`는 비트 연산인데, 여기선 "숫자가 너무 커지지 않게 잘라주는" 역할만 합니다.
> 깊게 몰라도 괜찮습니다.

### 6-2. 충돌(collision)과 체이닝

다른 이름표가 **우연히 같은 칸 번호**를 받을 수 있습니다. 이걸 "충돌"이라 합니다.
해결책은 **체이닝**: 한 칸에 여러 개가 오면 그 칸에 **줄을 세웁니다**.
이 "줄"로 아까 만든 **이중 연결 리스트를 재사용**합니다! (미션 권장사항)

```
칸 3번 → [user:1=Alice] ⇄ [user:9=Bob]   ← 같은 칸에 줄서기
```

### 6-3. 코드 작성

```python
from .dynamic_array import DynamicArray   # 없으면 그냥 [None]*n 리스트로 대체 가능
from .doubly_linked_list import DoublyLinkedList

class _Entry:
    """사물함에 들어가는 (이름표, 물건) 한 쌍."""
    def __init__(self, key, value):
        self.key = key
        self.value = value

_MISSING = object()   # "못 찾음"을 나타내는 특별한 표식

class HashMap:
    def __init__(self, initial_capacity=8):
        self._capacity = initial_capacity     # 칸 개수
        self._size = 0                        # 저장된 항목 수
        self._buckets = self._make_buckets(self._capacity)

    def _make_buckets(self, capacity):
        """칸마다 빈 줄(연결 리스트)을 준비."""
        buckets = []
        for _ in range(capacity):
            buckets.append(DoublyLinkedList())
        return buckets

    def _index_for(self, key, capacity):
        return self._hash(key) % capacity     # 칸 번호 = 해시값 % 칸수
```

> 📌 위에서 `DynamicArray` import가 부담되면, `self._buckets`를 그냥 파이썬
> 리스트로 써도 됩니다(`buckets = []`). 인덱스로만 접근하므로 허용 범위입니다.

해시 함수와 "찾기" 도우미를 추가합니다.

```python
    def _hash(self, key):
        h = 5381
        for ch in key:
            h = h * 33 + ord(ch)
            h = h & 0xFFFFFFFF
        return h

    def _find_entry(self, key):
        """key가 들어있는 (줄, 노드, 항목)을 찾는다. 없으면 (줄, None, None)."""
        idx = self._index_for(key, self._capacity)
        bucket = self._buckets[idx]              # 해당 칸의 줄
        for node in bucket.iter_nodes():         # 줄을 하나씩 확인
            if node.data.key == key:
                return bucket, node, node.data
        return bucket, None, None
```

> ⚠️ 여기서 `bucket.iter_nodes()`가 필요합니다. 연결 리스트에 아래 메서드를
> 추가하세요 (노드를 하나씩 꺼내주는 도우미):
> ```python
>     def iter_nodes(self):
>         cur = self._head.next
>         while cur is not self._tail:
>             yield cur
>             cur = cur.next
> ```
> `yield`는 "하나씩 돌려주는 반복 도구"를 만듭니다. for문에서 쓸 수 있게 됩니다.

이제 미션이 요구하는 메서드들:

```python
    def put(self, key, value):
        """저장(있으면 값만 교체). 너무 꽉 차면 칸을 2배로 늘림."""
        bucket, node, entry = self._find_entry(key)
        if entry is not None:
            entry.value = value          # 이미 있으면 값만 바꿈
            return
        bucket.insert_back(_Entry(key, value))   # 없으면 줄 맨 뒤에 추가
        self._size += 1
        if self._size > self._capacity * 0.75:   # 75% 넘으면
            self._resize(self._capacity * 2)     # 칸 2배 확장

    def get(self, key, default=None):
        _, _, entry = self._find_entry(key)
        return default if entry is None else entry.value

    def get_or_missing(self, key):
        """값이 None인 경우와 '키 없음'을 구분하려고 따로 둠."""
        _, _, entry = self._find_entry(key)
        return _MISSING if entry is None else entry.value

    def remove(self, key):
        bucket, node, entry = self._find_entry(key)
        if node is None:
            return False
        bucket.remove_node(node)
        self._size -= 1
        return True

    def contains(self, key):
        _, _, entry = self._find_entry(key)
        return entry is not None

    def keys(self):
        result = []
        for bucket in self._buckets:
            for node in bucket.iter_nodes():
                result.append(node.data.key)
        return result

    def items(self):
        result = []
        for bucket in self._buckets:
            for node in bucket.iter_nodes():
                result.append((node.data.key, node.data.value))
        return result

    def size(self):
        return self._size

    def capacity(self):
        return self._capacity
```

### 6-4. 칸 2배 늘리기 (rehash)

칸이 너무 꽉 차면(75% 초과) 충돌이 잦아져 느려집니다.
그래서 칸을 2배로 늘리고 **모든 항목을 새 칸 기준으로 다시 배치**합니다.

```python
    def _resize(self, new_capacity):
        old_buckets = self._buckets
        new_buckets = self._make_buckets(new_capacity)
        for bucket in old_buckets:
            for node in bucket.iter_nodes():
                entry = node.data
                idx = self._index_for(entry.key, new_capacity)  # 새 칸 번호 계산
                new_buckets[idx].insert_back(entry)
        self._buckets = new_buckets
        self._capacity = new_capacity
```

> 💡 **왜 0.75인가요?** 경험적으로 "속도와 메모리 낭비의 균형"이 좋은 값입니다.
> 너무 빽빽하면 느리고, 너무 헐겁게 두면 메모리가 낭비됩니다.

## 7. STEP 3 — 최소 힙 만들기

📁 `mini_redis/structures/min_heap.py`

### 무엇을, 왜 만드나?

TTL(유효기간)을 관리하려면 **"가장 먼저 만료될 키"** 를 빨리 찾아야 합니다.
**최소 힙**은 항상 **가장 작은 값이 맨 위**에 오는 특별한 더미입니다.
`(만료시각, 키)` 쌍을 넣으면, 만료시각이 가장 이른 것이 맨 위에 옵니다.

### 7-1. 핵심 아이디어: 배열로 트리 표현하기

힙은 "완전 이진 트리"인데, 복잡한 트리 대신 **그냥 리스트**로 표현합니다.

```
인덱스:  0   1   2   3   4
값:     [1,  3,  2,  8,  9]

규칙:
- i번 칸의 자식 = 2i+1, 2i+2
- i번 칸의 부모 = (i-1)//2
```

규칙(부모가 자식보다 항상 작거나 같다)만 지키면, 0번 칸이 늘 최솟값입니다.

### 7-2. 코드 작성

```python
class MinHeap:
    def __init__(self):
        self._data = []        # 그냥 리스트로 저장

    def _swap(self, i, j):
        self._data[i], self._data[j] = self._data[j], self._data[i]

    def _heapify_up(self, idx):
        """새로 넣은 값을 부모와 비교하며 위로 올린다."""
        while idx > 0:
            parent = (idx - 1) // 2
            if self._data[idx] < self._data[parent]:  # 내가 부모보다 작으면
                self._swap(idx, parent)               # 자리 바꾸고
                idx = parent                          # 위로 이동
            else:
                break

    def _heapify_down(self, idx):
        """맨 위 값을 자식과 비교하며 아래로 내린다."""
        n = len(self._data)
        while True:
            left = 2 * idx + 1
            right = 2 * idx + 2
            smallest = idx
            if left < n and self._data[left] < self._data[smallest]:
                smallest = left
            if right < n and self._data[right] < self._data[smallest]:
                smallest = right
            if smallest == idx:      # 더 내려갈 곳 없으면 끝
                break
            self._swap(idx, smallest)
            idx = smallest

    def push(self, item):
        """추가: 맨 뒤에 넣고 위로 올림."""
        self._data.append(item)
        self._heapify_up(len(self._data) - 1)

    def pop(self):
        """최솟값 꺼내기: 맨 위를 빼고, 맨 뒤 값을 위로 올린 뒤 정리."""
        n = len(self._data)
        if n == 0:
            return None
        root = self._data[0]
        last = self._data.pop()
        if n > 1:
            self._data[0] = last
            self._heapify_down(0)
        return root

    def peek(self):
        """꺼내지 않고 최솟값만 본다. (맨 위)"""
        return self._data[0] if self._data else None

    def size(self):
        return len(self._data)

    def is_empty(self):
        return len(self._data) == 0
```

> 🎨 **push 동작 예시**: `[1,3,2]`에 `0`을 넣으면
> ① 맨 뒤 추가 `[1,3,2,0]` → ② 0이 부모(3)보다 작으니 교환 `[1,0,2,3]`
> → ③ 0이 부모(1)보다 작으니 교환 `[0,1,2,3]`. 끝! 0이 맨 위로.

> 💡 `(만료시각, 키)` 튜플을 넣으면 튜플 비교 규칙(앞 원소 먼저 비교) 덕분에
> 만료시각이 이른 순서로 자동 정렬됩니다.

### 8-1. 엔진이 들고 있는 그릇들

```python
import time
from .structures.hash_map import HashMap, _MISSING
from .structures.doubly_linked_list import DoublyLinkedList
from .structures.min_heap import MinHeap

def _utf8_len(s):
    """문자열의 실제 바이트 크기 (메모리 계산용)."""
    return len(s.encode("utf-8"))

class OOMError(Exception):
    """메모리 초과로 저장 불가할 때 발생시키는 에러."""

class MiniRedis:
    def __init__(self, time_func=None):
        # time_func: 시계. 테스트 때 '가짜 시계'를 끼워넣기 위해 분리.
        self._now = time_func if time_func is not None else time.time

        self._store   = HashMap()           # 키 → 값 (진짜 데이터)
        self._nodes   = HashMap()           # 키 → 리스트 노드 (LRU용)
        self._lru     = DoublyLinkedList()  # 사용 순서 (앞=최근, 뒤=오래됨)
        self._expires = HashMap()           # 키 → 만료시각
        self._ttl_heap = MinHeap()          # (만료시각, 키) 더미

        self._maxmemory = 0      # 0 = 무제한
        self._used_memory = 0    # 현재 사용량
        self._evicted_keys = 0   # 쫓아낸 키 개수
```

> 🔑 **여기가 핵심**: `_store`(값)와 `_nodes`(노드 위치)를 **둘 다** 둡니다.
> - 값을 빨리 찾으려고 → 해시맵 `_store`
> - 사용 순서를 빨리 바꾸려고 → 연결 리스트 `_lru`
> - 그 리스트의 노드를 빨리 찾으려고 → 해시맵 `_nodes`
>
> 이 조합 덕분에 LRU 갱신이 **O(1)** 이 됩니다.

### 8-2. SET (저장)

순서가 중요합니다. 천천히 따라가세요.

```python
    def set(self, key, value):
        entry_size = _utf8_len(key) + _utf8_len(value)

        # ① 단일 항목이 한계보다 크면 아예 저장 불가
        if self._maxmemory > 0 and entry_size > self._maxmemory:
            raise OOMError()

        existing = self._store.get_or_missing(key)
        if existing is not _MISSING:
            # ② 이미 있는 키 → 덮어쓰기
            self._used_memory -= _utf8_len(key) + _utf8_len(existing)  # 옛 크기 빼고
            self._store.put(key, value)
            self._used_memory += entry_size                            # 새 크기 더함
            if self._expires.contains(key):
                self._expires.remove(key)   # 덮어쓰면 유효기간 초기화(규칙)
            self._touch_lru(key)            # 최근 사용 표시
        else:
            # ③ 새 키
            self._store.put(key, value)
            self._used_memory += entry_size
            node = self._lru.insert_front(key)   # 줄 맨 앞에 세우고
            self._nodes.put(key, node)           # 그 노드를 기억

        # ④ 한계 넘으면 오래된 것부터 버림
        self._evict_until_within_limit()
        return "OK"
```

### 8-3. LRU 도우미 2개

```python
    def _touch_lru(self, key):
        """방금 쓴 키를 줄 맨 앞으로. O(1)."""
        node = self._nodes.get_or_missing(key)
        if node is not _MISSING:
            self._lru.move_to_front(node)

    def _evict_until_within_limit(self):
        """한계 이하가 될 때까지 가장 오래된 키를 버린다."""
        if self._maxmemory <= 0:
            return                                  # 0이면 무제한
        while self._used_memory > self._maxmemory and not self._lru.is_empty():
            lru_key = self._lru.back_node().data    # 줄 맨 뒤 = 가장 오래됨
            self._delete_key(lru_key)               # 삭제
            self._evicted_keys += 1                 # 쫓아낸 수 +1
```

### 8-4. 키 완전 삭제 (모든 그릇에서)

```python
    def _delete_key(self, key):
        """데이터/LRU/유효기간 모든 곳에서 제거 + 메모리 차감."""
        value = self._store.get_or_missing(key)
        if value is _MISSING:
            return False
        self._used_memory -= _utf8_len(key) + _utf8_len(value)
        self._store.remove(key)
        node = self._nodes.get_or_missing(key)
        if node is not _MISSING:
            self._lru.remove_node(node)
            self._nodes.remove(key)
        if self._expires.contains(key):
            self._expires.remove(key)
        return True
```

### 8-5. 만료 확인 + GET

```python
    def _is_expired(self, key):
        exp = self._expires.get_or_missing(key)
        if exp is _MISSING:
            return False               # 유효기간이 없으면 안 만료됨
        return exp <= self._now()      # 만료시각이 지났으면 True

    def _ensure_alive(self, key):
        """살아있으면 True. 만료됐으면 삭제하고 False."""
        if not self._store.contains(key):
            return False
        if self._is_expired(key):
            self._delete_key(key)      # 만료 → 삭제
            return False
        return True

    def get(self, key):
        if not self._ensure_alive(key):
            return None                # 없거나 만료 → nil
        value = self._store.get(key)
        self._touch_lru(key)           # 성공했을 때만 최근 사용 표시
        return value
```

> 📌 **GET 순서 기억하기**: 만료 확인 → (만료면 삭제 후 None, LRU 갱신 안 함)
> → 살아있으면 값 가져오고 → LRU 맨 앞으로 → 값 반환.

### 8-7. 힙으로 만료 정리하기

```python
    def _purge_expired_from_heap(self):
        """힙 맨 위(가장 이른 만료)부터 확인하며 만료/낡은 것 정리."""
        now = self._now()
        while not self._ttl_heap.is_empty():
            expire_at, key = self._ttl_heap.peek()
            current = self._expires.get_or_missing(key)
            # 힙에 남은 정보가 현재와 다르면(유효기간 바뀜/삭제됨) 버림
            if current is _MISSING or current != expire_at:
                self._ttl_heap.pop()
                continue
            if expire_at <= now:        # 진짜 만료됨
                self._ttl_heap.pop()
                if self._store.contains(key):
                    self._delete_key(key)
                continue
            break    # 맨 위가 아직 안 만료 → 나머지도 안 만료(끝)
```

> 💡 **왜 맨 위만 보고 멈추나요?** 힙은 맨 위가 가장 이른 만료입니다.
> 맨 위가 아직 안 만료면 그 아래는 더 나중이니 볼 필요가 없습니다. → 빠름!
>
> 💡 **"낡은(stale) 정보"란?** 유효기간을 다시 설정하면 힙에 옛 정보가 남습니다.
> 즉시 지우긴 어려워서, 꺼낼 때 "지금 정보와 다르면 버리는" 방식(lazy deletion)을 씁니다.

```python
        return [
            "used_memory:" + str(self._used_memory),
            "maxmemory:" + str(self._maxmemory),
            "evicted_keys:" + str(self._evicted_keys),
        ]

    def expire(self, key, seconds_str):
        seconds = _parse_int(seconds_str)
        if not self._ensure_alive(key):
            return 0                       # 없는 키
        if seconds <= 0:
            self._delete_key(key)          # 0 이하 → 즉시 만료
            return 1
        expire_at = self._now() + seconds
        self._expires.put(key, expire_at)
        self._ttl_heap.push((expire_at, key))   # 힙에도 등록
        return 1

    def ttl(self, key):
        if not self._ensure_alive(key):
            return -2                      # 없는 키
        exp = self._expires.get_or_missing(key)
        if exp is _MISSING:
            return -1                      # 유효기간 없음
        remaining = exp - self._now()
        if remaining < 0:
            remaining = 0
        return int(remaining)              # 남은 초(소수점 버림)

    # 상태 확인용(테스트/디버깅)

    def evicted_keys(self): return self._evicted_keys
    def maxmemory(self):    return self._maxmemory
```

### 8-9. 숫자 변환 도우미 (파일 맨 아래)

```python
def _parse_int(s):
    try:
        return int(s)
    except (TypeError, ValueError):
        raise ValueError("not an integer")

def _parse_nonneg_int(s):
    n = _parse_int(s)
    if n < 0:
        raise ValueError("must be non-negative")
    return n
```

## 9. STEP 5 — CLI 만들기 (사용자 화면)

📁 `mini_redis/cli.py`

사용자가 친 글을 **잘게 쪼개고(파싱)**, 엔진을 부르고, 결과를 **Redis 스타일**로 출력합니다.

### 9-1. 입력 쪼개기 (따옴표 지원)

`SET k "Alice Smith"` 처럼 따옴표 안 공백은 한 덩어리로 봐야 합니다.

```python
def tokenize(line):
    """한 줄을 토큰(단어) 리스트로 쪼갠다. 따옴표 안은 한 덩어리."""
    tokens = []
    i = 0
    n = len(line)
    while i < n:
        while i < n and line[i].isspace():   # 공백 건너뛰기
            i += 1
        if i >= n:
            break
        if line[i] == '"':                   # 따옴표 시작
            i += 1
            buf = []
            closed = False
            while i < n:
                if line[i] == '"':           # 따옴표 끝
                    closed = True
                    i += 1
                    break
                buf.append(line[i])
                i += 1
            if not closed:
                raise ValueError("unbalanced quotes")   # 안 닫힘
            tokens.append("".join(buf))
        else:                                # 보통 단어
            buf = []
            while i < n and not line[i].isspace():
                buf.append(line[i])
                i += 1
            tokens.append("".join(buf))
    return tokens
```

### 9-2. 에러 메시지 상수

```python
def err_unknown(cmd):
    return "(error) ERR unknown command '" + cmd + "'"

def err_args(cmd):
    return "(error) ERR wrong number of arguments for '" + cmd + "' command"

ERR_NOT_INT = "(error) ERR value is not an integer or out of range"
```

### 9-3. 명령 실행기

```python
from .engine import MiniRedis, OOMError

class CommandError(Exception):
    def __init__(self, message):
        self.message = message

class CLI:
    def __init__(self, engine=None):
        self.engine = engine if engine is not None else MiniRedis()

    def execute(self, line):
        try:
            tokens = tokenize(line)
        except ValueError:
            return ERR_UNBALANCED
        if not tokens:
            return None                     # 빈 줄은 무시

        cmd = tokens[0].upper()             # 명령은 대소문자 무시
        args = tokens[1:]

        if cmd in ("EXIT", "QUIT"):
            raise SystemExit(0)             # 종료

        try:
            return self._dispatch(cmd, tokens[0], args)
        except CommandError as e:
            return e.message
        except OOMError:
            return ERR_OOM

    def _dispatch(self, cmd, raw_cmd, args):
        """명령 이름에 따라 알맞은 처리 함수로 보낸다."""
        if cmd == "SET":    return self._cmd_set(args)
        if cmd == "GET":    return self._cmd_get(args)
        if cmd == "DEL":    return self._cmd_del(args)
        if cmd == "EXISTS": return self._cmd_exists(args)
        if cmd == "DBSIZE": return self._cmd_dbsize(args)
        if cmd == "KEYS":   return self._cmd_keys(args)
        if cmd == "CONFIG": return self._cmd_config(args)
        if cmd == "INFO":   return self._cmd_info(args)
        if cmd == "EXPIRE": return self._cmd_expire(args)
        if cmd == "TTL":    return self._cmd_ttl(args)
        return err_unknown(raw_cmd)
```

> 💡 `dict` 금지라서 if문을 줄줄이 씁니다. 명령이 몇 개 안 되니 괜찮습니다.

### 9-4. 각 명령 처리 함수

```python
    def _cmd_set(self, args):
        if len(args) != 2:
            raise CommandError(err_args("set"))
        return self.engine.set(args[0], args[1])

    def _cmd_get(self, args):
        if len(args) != 1:
            raise CommandError(err_args("get"))
        value = self.engine.get(args[0])
        if value is None:
            return "(nil)"
        return '"' + value + '"'           # "값" 형태로

    def _cmd_del(self, args):
        if len(args) != 1:
            raise CommandError(err_args("del"))
        return "(integer) " + str(self.engine.delete(args[0]))

    def _cmd_exists(self, args):
        if len(args) != 1:
            raise CommandError(err_args("exists"))
        return "(integer) " + str(self.engine.exists(args[0]))

    def _cmd_dbsize(self, args):
        if len(args) != 0:
            raise CommandError(err_args("dbsize"))
        return "(integer) " + str(self.engine.dbsize())

    def _cmd_keys(self, args):
        if len(args) != 0:
            raise CommandError(err_args("keys"))
        keys = self.engine.keys()
        if not keys:
            return "(empty array)"
        lines = []
        i = 1
        for k in keys:
            lines.append(str(i) + '. "' + k + '"')   # 1. "키" 형식
            i += 1
        return "\n".join(lines)

    def _cmd_config(self, args):
        if len(args) < 1:
            raise CommandError(err_args("config"))
        if args[0].upper() == "SET":
            if len(args) != 3 or args[1].lower() != "maxmemory":
                raise CommandError(err_args("config|set"))
            try:
                return self.engine.config_set_maxmemory(args[2])
            except ValueError:
                raise CommandError(ERR_NOT_INT)
        raise CommandError("(error) ERR Unknown CONFIG subcommand")

    def _cmd_info(self, args):
        return "\n".join(self.engine.info_memory())

    def _cmd_expire(self, args):
        if len(args) != 2:
            raise CommandError(err_args("expire"))
        try:
            result = self.engine.expire(args[0], args[1])
        except ValueError:
            raise CommandError(ERR_NOT_INT)
        return "(integer) " + str(result)

    def _cmd_ttl(self, args):
        if len(args) != 1:
            raise CommandError(err_args("ttl"))
        return "(integer) " + str(self.engine.ttl(args[0]))
```

### 9-5. REPL (입력 반복 루프)

REPL = Read(읽고)-Eval(실행하고)-Print(출력하고)-Loop(반복).

```python
import sys

def repl(input_stream=None, output_stream=None):
    istream = input_stream if input_stream is not None else sys.stdin
    ostream = output_stream if output_stream is not None else sys.stdout
    cli = CLI()

    while True:
        ostream.write("mini-redis> ")    # 프롬프트 출력
        ostream.flush()
        line = istream.readline()         # 한 줄 읽기
        if not line:                      # Ctrl+D(입력 끝)
            ostream.write("\n")
            break
        line = line.rstrip("\n")
        try:
            result = cli.execute(line)
            if result is not None:
                ostream.write(result + "\n")
                ostream.flush()
        except SystemExit:
            break

if __name__ == "__main__":
    repl()
```

## 11. 막히기 쉬운 부분 (FAQ)

**Q. `ModuleNotFoundError: No module named 'mini_redis'` 가 떠요.**
A. `main.py`가 있는 폴더(프로젝트 최상단)에서 실행하세요. 또 각 폴더에
`__init__.py`가 있는지 확인하세요.

**Q. `from .structures...` 의 점(`.`)은 뭔가요?**
A. "같은 패키지 안에서" 가져온다는 표시(상대 경로)입니다. 패키지로 실행할 때 필요합니다.

**Q. 연결 리스트에서 `iter_nodes`가 없다고 에러나요.**
A. STEP 1에서 만든 리스트에 6-3에 적힌 `iter_nodes` 메서드를 추가했는지 확인하세요.
해시맵이 이 메서드를 사용합니다.

**Q. `_MISSING`은 왜 필요한가요?**
A. 값으로 `None`을 저장할 수도 있어서, "값이 None"인 경우와 "키 자체가 없음"을
구분하려고 특별한 표식을 따로 둔 것입니다.

**Q. 메모리(`used_memory`)는 어떻게 계산하나요?**
A. `모든 (키 글자수 + 값 글자수)의 합`입니다. 노드나 포인터 같은 내부 구조의
크기는 세지 않습니다(미션 규칙). 한글은 UTF-8에서 글자당 3바이트라 `encode`로 셉니다.

**Q. 왜 굳이 어렵게 직접 만드나요? `dict` 쓰면 안 되나요?**
A. 됩니다. 하지만 이 프로젝트의 **목적이 "내부 원리를 직접 체험"** 하는 것이라
일부러 금지했습니다. 원리를 알면 어떤 언어/상황에서도 응용할 수 있습니다.

## 12. 응용 과제 — 직접 확장해보기

다 만들었다면 아래에 도전하며 실력을 키워보세요. 난이도 순입니다.

### 🥉 초급
1. **`FLUSHALL` 명령 추가**: 모든 키를 한 번에 삭제. (엔진에 메서드 추가 → CLI 분기 추가)
2. **`APPEND key value` 명령**: 기존 값 뒤에 문자열 붙이기. (GET → 합치기 → SET)
3. **`KEYS`를 정렬해서 출력**: `sorted()`를 활용.

### 🥈 중급
4. **`INCR key` 명령**: 숫자 값을 1 증가. (정수 변환 에러 처리도 함께)
5. **동적 배열 직접 구현**: 힙/해시맵의 내부 리스트를 `[None]*n` 기반으로 교체.
   (보너스 5.1) — `append`, `get`, `set`, 2배 확장 로직 만들기.
6. **`TTL`을 올림(ceil)으로 바꾸기**: 실제 Redis와 더 비슷하게.

### 🥇 고급
7. **LFU 정책으로 바꾸기**: "가장 적게 쓴 것"을 버리도록. 키마다 사용 횟수를
   세는 구조가 추가로 필요합니다. ([DESIGN.md](DESIGN.md) 항목 4-4 참고)
8. **Pub/Sub 만들기**(보너스 5.5): `SUBSCRIBE`/`PUBLISH`. 채널별 구독자 목록에
   연결 리스트(큐)를 재사용.
9. **스택/큐/덱, 이진 트리/BST 만들기**(보너스 5.2~5.4):
   [STACK_QUEUE_DEQUE.md](STACK_QUEUE_DEQUE.md) 참고.
