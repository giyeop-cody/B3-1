# B3-1 동료평가 대비 가이드

## 1. 이 과제가 뭔가요?
dict를 쓰지 말고 해시 테이블을 직접 구현하는 과제.

## 2. 평가 예상 질문
Q1. 해시 함수 설계?
A. 문자열의 각 문자 ord 값 합산 + 모듈러 연산. 분산성과 결정성 고려.

Q2. 충돌 해결 방법?
A. 체이닝 — 같은 해시값이면 연결 리스트로 연결. 구현 단순, 메모리 유연.

Q3. O(1)이 보장되는 조건?
A. 해시 함수가 잘 분산 + 테이블 크기 충분 + 충돌 적을 때.

Q4. dict 금지의 의도?
A. 편한 도구를 빼앗아 원리를 이해하게 함. dict가 어떻게 O(1)을 달성하는지 체득.

Q5. LRU 캐싱 원리?
A. 가장 오래 사용 안 한 것부터 제거. 순서 관리로 접근 시간 추적.
